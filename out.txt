g++ -I. -Iclasses -Iclasses/lifeforms -Iclasses/supersets classes/*.cpp classes/lifeforms/*.cpp classes/supersets/*.cpp cpp.cpp -o test

-I. == include cwd

-Iclasses == include dir classes in cwd to look for headers

-Iclasses/lifeforms == include lifeforms in classes to look for headers

classes/*.cpp == include all cpp files for linking and compilation; same with classes/lifeforms; expands to all .cpp files directly inside of these dirs

cpp.cpp == main sourcefile

-o test == output to file called "test" in cwd

if any folder does not include .h/.cpp files and its included ie -Iexample example/*.cpp then itll throw an error, so just fill it with an empty header and cpp file
